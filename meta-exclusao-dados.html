Exclusão de Dados · Arthur MCP

Última atualização: 29 de outubro de 2026

1Quais dados existem

O Arthur MCP não mantém servidor nem banco de dados próprio. Os únicos dados guardados são os tokens de acesso, armazenados localmente no computador do usuário.

2Remover o acesso pelo Facebook

Acesse o Facebook › Configurações e privacidade › Configurações › Segurança e login (ou Aplicativos e sites), localize o app Arthur MCP e clique em Remover. Isso invalida os tokens e encerra todo acesso do aplicativo aos seus dados.

3Pedir exclusão por e-mail

Se preferir, envie um e-mail para torresxarthur@gmail.com com o assunto "Exclusão de dados – Arthur MCP". Qualquer dado relacionado à sua conta será apagado em até 30 dias, e você receberá uma confirmação.
