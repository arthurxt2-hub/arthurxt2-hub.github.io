Política de Privacidade · Arthur MCP

Última atualização: 29 de outubro de 2026

1Sobre o aplicativo

O Arthur MCP é uma ferramenta interna, de uso exclusivo de Arthur Torres, que se conecta à Marketing API da Meta para consultar dados e gerenciar campanhas das contas de anúncio do Facebook e do Instagram às quais o próprio usuário já tem acesso. O aplicativo não é oferecido ao público e não coleta dados de outras pessoas.

2Dados acessados

Mediante autorização do usuário pelo Login do Facebook, o aplicativo acessa dados das contas de anúncio e páginas autorizadas (como campanhas, conjuntos de anúncios, anúncios, criativos, públicos, métricas de desempenho e configurações) e as informações básicas do perfil usado no login (nome e ID).

3Uso dos dados

Os dados são usados apenas para gerar análises, relatórios e ajustes de campanhas solicitados pelo próprio usuário. Não são vendidos, compartilhados com terceiros nem usados para publicidade ou para criar perfis de pessoas.

4Armazenamento e segurança

Os tokens de acesso ficam armazenados localmente no computador do usuário. O aplicativo não possui servidor próprio e não mantém banco de dados com informações vindas da Meta.

5Termos da Meta

O uso dos dados recebidos da Meta segue os Termos da Plataforma Meta e as Políticas para Desenvolvedores.

6Revogação e exclusão de dados

O acesso pode ser revogado a qualquer momento em Configurações do Facebook › Segurança e login › Aplicativos e sites. Para pedir a exclusão de dados, veja as instruções de exclusão de dados.
